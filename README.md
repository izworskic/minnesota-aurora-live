# Minnesota Aurora Live

Independent state aurora decision tool modeled after the successful Michigan Northern Lights experience.

- Canonical: `https://chrisizworski.com/national-tools/aurora/minnesota/`
- Default region: `voyageurs`
- Runtime: Vercel static HTML + Node serverless API
- Primary sources: NOAA SWPC, NWS API, U.S. Naval Observatory
- No database, paid API, Replit runtime, or Michigan runtime dependency

Run `npm test` and `npm run build` before release. This repository must not modify or redirect the Michigan Northern Lights implementation.
